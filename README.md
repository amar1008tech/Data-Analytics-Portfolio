#  Sales Performance Dashboard using Microsoft Excel

##  Project Overview

This project focuses on analyzing sales data and building an interactive Sales Performance Dashboard using Microsoft Excel.

The dashboard helps understand business performance through sales trends, product categories, regions, cities, sales channels, and payment methods.

##  Project Objectives

* Analyze overall sales performance.
* Identify the highest-performing product category.
* Compare sales across different regions and cities.
* Understand sales channel performance.
* Analyze customer payment preferences.
* Track monthly sales trends.
* Build an interactive dashboard for business insights.

##  Tools & Technologies

* Microsoft Excel
* Excel Tables
* Data Cleaning
* PivotTables
* PivotCharts
* Slicers
* Timeline
* Excel Formulas

##  Data Cleaning

The dataset was cleaned and prepared before analysis.

Key cleaning activities:

* Identified and removed duplicate Order IDs.
* Handled missing values using "Unknown".
* Corrected inconsistent text values.
* Corrected invalid quantity values.
* Identified and handled invalid dates.
* Verified numerical sales values.
* Checked data consistency.

##  Dashboard Features

The interactive dashboard contains:

### KPI Cards

* Total Sales
* Total Orders
* Best-Selling Category
* Best-Performing Region

### Visualizations

* Monthly Sales Trend
* Category-wise Sales
* Regional Sales Performance
* Sales Channel Performance
* Payment Method Analysis
* City-wise Sales Performance

### Interactive Filters

* Region
* Category
* Sales Channel
* Payment Method
* Monthly Timeline

All filters are connected to the PivotTables and update the dashboard interactively.
